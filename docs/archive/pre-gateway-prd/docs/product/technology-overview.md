## Granica licencji i instalacji

Nowe zależności produktu to co najwyżej SDK MCP i mały runner TypeScript, jeśli pierwsze testy tego wymagają. Laya nie wchodzi do bundla Vercel; jego checkpoint i Python pozostają w opcjonalnym lokalnym procesie. Materiał OWASP służy do mapowania i cytowania, nie do kopiowania całych przykładów. Dokładna licencja każdego zewnętrznego zasobu i link do niej są w raporcie badawczym; przed dodaniem kodu lub danych do repo integrator przypina źródło, wersję i pochodzenie.

## Warunki, które trzeba zweryfikować przed deklaracją działania

Brak `.env.local`, powiązania `.vercel` i wpisu o zastosowanej migracji w `supabase/APPLIED.md` oznacza, że dostęp do usług nie został jeszcze lokalnie potwierdzony. Próba MCP i inferencja Laya również nie zostały wykonane. Żaden z tych statusów nie jest zastępowany zielonym buildem. Właściciel/integrator aktualizuje tę tabelę dopiero po sprawdzeniu odpowiedniej usługi lub uruchomieniu testu.
